## 2. Implementation changes (all before the freeze)
Comparative thresholds on related tables; unknown comparatives never read as "="; polarity-named flags
(`sensor_ok`) need the polarity word or an antonym, negation-aware; comparative/antonym words count as
explained only when the plan applied the filter; "average X per <base row>" is a per-row mean; expanded
abbreviation aliases (`pax_cnt` -> passengers); new `count_of_measure_noun` type check; key-suffix FK
inference tier for TEXT keys; fan-out semi-join for value-qualified nouns ("High priority tickets");
"at least / at most"; research-only ablation switches (`INSIGHTFLOW_ABLATE`, default off). Details:
`01_semantic_capability_matrix.md`. The fail-closed semantic-verifier fix is in `b11793b`.

## 7. First-run results (A0, frozen build, run once)
Correct 14/74 (18.9%, 95% CI 11.6-29.3); answered 17/74; accuracy when answered 14/17; wrong answers 7/105
(3 wrong values + 4 answers to clarify items); appropriate refusals 27/31; unnecessary clarifications 57/74;
latency p50 54 ms, p95 660 ms. Without the 20 borderline items: 14/65 correct, 5/85 wrong. Coverage is far below
the developer-authored first runs (K1 42/54).

## 8. Ablations
All six safeguards off: 17 correct, 32 wrong. Coverage + wording checks alone prevent 24 errors (cost: 3 correct
answers); semantic layer alone prevents 4 (cost: 0). Confidence gate, result consistency, plan fidelity and answer
verifier changed nothing on this set. A5 is confounded (two checks in one stage). `04_ablation_analysis.md`.

## 9. Confidence

by answer shape. The score is not calibrated; safety comes from vetoes. `05_confidence_analysis.md`.
